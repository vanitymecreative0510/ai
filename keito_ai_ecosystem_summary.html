📝 ケース①：YouTube動画からブログ記事（ktlog.net）が1本完成するまで 31:22 - 33:09
  1. 1. 依頼とフック発動： 「このYouTube動画を ktlog.net の記事にして」とリンクを渡すと、フックが発動し、Jevが依頼の種類を判定してブログ作成スキル（ktlog-youtube-article）を選択。
  2. 2. 素材解析とWeb検索： 動画の文字起こしを取得して構成を組み立て、最新情報の裏付けをGoogle検索で調査。さらに動画画面を切り出してHTML/WebPで図解を作成。
  3. 3. SEO設計と本文執筆： 検索上位を狙うタイトル・概要文を作成し、文体ナレッジ（JLS+）に従って本文を執筆・推敲。
  4. 4. EmDash連携と元資料照合： Jevの判定後、EmDashのMCP経由で下書きを投入。専属チェッカー（emdash-content-reviewer）が「元の動画内容とズレがないか」を照合し、問題があればステップ2へ差し戻し。合格後に人間が確認して公開！
🎬 ケース②：広告・プロモーション動画が1本完成するまで（所要20〜30分） 33:10 - 35:02
  1. 1. デザイン番号指定（MOTION VAULT）： HTMLカタログからデザイン番号を選び /motion-vault スキルで依頼。フックとJevが方針を決定。
  2. 2. 音声合成とBGM生成： ナレーション原稿を作成して音声合成（ElevenLabs / Gemini TTS）し、BGMを生成。
  3. 3. 「1秒ごとの要素」を静止画として組む： いきなり動画にするのではなく、1秒ごとのコマを画像として生成・配置し、静止画の状態で文字崩れやレイアウトを検査（崩れていればその場で修正）。
  4. 4. 動画化とトリプル検品： 静止画を重ねてアニメーション動画（MP4）を書き出し → 専属エージェントが検品 → 動画に強いGemini (Antigravity) に完成動画を見せてカットや動きをレビュー → 最後にJevが最終判定して完成！

  3. 3. 【重要】人間（KEITO氏）への確認ステップ： お金に関わる処理のため、勝手に送信せず必ず一度人間側に確認を入れるフローを挟む。
