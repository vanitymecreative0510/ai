機能 1〜2：公式Google Workspace連携と「偽の仕事」にならないMod活用

機能 #1：Claude in Google Docs / Sheets / Slides（公式ネイティブ連携）

00:00〜01:41

サードパーティ製プラグインではなく、Anthropic公式のネイティブ連携アドオンが登場。

🛠️ セットアップ手順（2ステップ） ① Google Workspace Marketplaceで「Claude」を検索してインストール。
② Docs/Sheets/Slidesの「拡張機能」＞「アドオン」＞「アドオンを取得」から再度Claudeを有効化すると右サイドバーに出現。
🔥 なぜスプレッドシート勢が絶賛しているのか？ ・サイドバーから自作スキルやSlack等のコネクタを直接呼び出せる。
・何より「ネイティブな書式設定・シートの数式・スライドのテーマ情報」を正確に理解して直接編集できるため、実用性が別次元に進化。

機能 #2：Claude Mods（ハイパーパーソナライゼーションと「偽の仕事」への警告）

01:42〜04:58

プロンプトで説明するだけでClaude Codeの入力バーや内部フック（挙動）を改造できる機能。ただしポール・グレアムの名言「時間を失う最も危険な方法は、遊ぶことではなく『偽の仕事（Fake Work）』に時間を費やすこと」の通り、見た目だけのMod作りに熱中するのは危険。「実際に何の成果に役立ったか？」で厳選すべき。

⭕ 本当に役立つMod ①：Burn-Meter（使用量計） トークン消費状況と制限までの残量を可視化するMod。既存品を入れるだけでなく、プロンプトで自分用のバージョンを作らせて仕組みを掴むのがおすすめ。
⭕ 本当に役立つMod ②：Reflect（自己改善通知） 会話中に「それは違う」とAIを修正した際、「その修正を永続的なルールとして保存しますか？」と自動通知するMod。同じ指摘の繰り返しを根絶できる。
⚠️ 注意：作ったModはその会話内で消えるため、必ず「プラグインとして保存・インストールして」と指示すること。
06:20 - 12:33

機能 3〜5：数値の裏付け検証・プロジェクト自動分割・Haikuのコスト革命

機能 #3：Claude Dashboards（「数値の根拠を表示」でAIのハルシネーションを検証）

06:20〜08:16

アーティファクトのダッシュボードテンプレートを選び「このプロジェクトで最も役立つダッシュボードを作って」と指示するだけで、外部データと連携した定期更新ダッシュボードが完成する。
🔍 最大の革新「See where the numbers come from（数値の根拠を表示）」：
数字の横のボタンをクリックすると、その数値を算出した「生データ」と「正確な計算式」がすべて表示される。「AIが出した数字をそのまま経営判断に使っていいのか？」という最大の不安を解消する「信頼せよ、されど確認せよ（Trust, but verify）」機能。

機能 #4：Claude Code内の「Projects」

08:17〜10:36

※通常のClaudeチャットのプロジェクトとは別物。
複数のチャットウィンドウを開いて「どのウィンドウに入力すべきか」迷うボトルネックを解消。1つの継続的な会話が「コーディネーター」となり、会話内容に応じて裏側で自動的にスレッドを分割・並列実行し、人間の入力が必要なものだけを知らせてくれる。

機能 #5：新型 Haiku（コスト75%削減の衝撃）

10:37〜12:33

従来比で実行コストが約75%削減（入力100万トークン約10セント／出力約50セント）され、「ドル単位からセント単位」へ突入。
顧客やチーム向けツールにAPIを組み込む際、OpusやSonnetでは高すぎた壁が消滅。既存ツールのモデルをHaikuに置き換えたり、ダッシュボードへ直接AIを組み込む採算が完全に成立するようになった。

12:34 - 17:27

機能 6〜7：AIっぽさを消すスライド作成術 ＆ スマホ遠隔操作コンボ

機能 #6：Claude Artifactsの「ドキュメント」と「スライド」

12:34〜14:43

マイルール：「メールより長い文章（提案書・マーケ資料・SNS長文）はすべてArtifactドキュメントで作る」。その場で直接編集でき、テキストをハイライトして部分修正指示も出せる。
また、スライド機能（PPTX/PDF/Googleスライド書き出し対応）でありがちな「AI特有の安っぽさ」を消す3つの鉄則：

① デザインシステムを取り込む 自社ブランドのアセットを読み込ませる（未作成なら designmd.app 等を参考に数時間かけてでも一度作れば、全出力が自社ブランド化する）。
②「1つの思考ルール」 AIを開く前に、必ず最低1つは自分自身の独自アイデアを考え、それを洗練・検証・膨らませるためにAIを使う。
③ 5パターン作らせて選ぶ 1つではなく「5つの異なるバリエーション」を反復生成させ、ベストな1つを選んでから微調整する（※共有相手もClaudeアカウントが必要）。

機能 #7：Remote Control（/remotecontrol）＋ Awake（スリープ防止）

14:44〜17:27

クラウドではなく自分のPC（ローカル）でClaudeを動かすと直接ファイルを編集でき構成もシンプルだが、「PCを開いておく必要がある」のが唯一の弱点。これを以下の2段コンボで完全解決：

📲 Step 1：/remotecontrol でスマホ連携 チャット欄に /remotecontrol と入力するだけで、ローカルPC上のセッションをスマホからそのまま監視・操作可能に。
⚡ Step 2：スリープ防止設定（Awake） Claudeデスクトップの「設定 ＞ Claude Code」で「動作中はスリープさせない」と「バッテリー駆動時もスリープさせない」を両方ONにする（またはターミナルで3時間起動維持する awake コマンドを設定）。これで30〜40分かかるビルド中にジムやサウナへ行ける！

⚖️ 総まとめ：「Claudeと話す人」vs「Claudeを管理・統括する人」の5大シフト

領域 ❌ 従来の使い方（Talking to Claude） ⭕ 新時代の管理術（Managing Claude）
1. 作業する場所 Claudeで作った文章や表を、毎回10分かけてGoogle DocsやSheetsへ手作業でコピペ移動する。 公式Google WorkspaceアドオンやArtifact Docs/Slidesを使い、チームの作業場所で直接スキル・数式・書式を動かす。
2. 作業環境の設計 デフォルト画面のまま何度も同じ修正指示を繰り返すか、見栄えだけの「偽の仕事」Modで時間を潰す。 修正を永続ルール化する「Reflect Mod」や使用量計「Burn-Meter」をプラグイン保存し、環境を継続改善する。
3. タスクの委譲とコスト 複数ウィンドウを手動で行き来し、すべて高価なOpus/Sonnetで回してAPI予算がパンクする。 Claude Code Projectsにスレッド分割を任せ、定型・大量処理はコスト75%減のHaiku（100万トークン10セント）へ委譲。
4. 数値の信頼性検証 AIが出したグラフや数値を「たぶん合っているだろう」と盲信するか、不安で使えない。 Claude Dashboardsの「数値の根拠を表示」で、生データと計算式をワンクリックで裏付け確認する。
5. 働く場所の自由度 30〜40分かかるローカルビルドが終わるまで、PCの前で画面を見張っている。 /remotecontrol ＋ スリープ防止（Awake）で、外出先やジムからスマホでローカルビルドを監視・操作する。
① ツール連携とドキュメント作成（機能1・6）
❌ Before：Claudeの出力をGoogle DocsやSheetsに毎回コピペし、AI特有の安っぽいスライドを作る。
⭕ After：公式Google WorkspaceアドオンとArtifact Docsで直接編集。スライドは「デザインシステム＋1思考ルール＋5案生成」で高品質化。
② 環境改造と数値の裏付け検証（機能2・3）
❌ Before：同じ修正を何度も繰り返す。AIが出したダッシュボードの数字が正しいか分からず不安になる。
⭕ After：修正を永続ルール化する「Reflect Mod」を導入し、ダッシュボードの「数値の根拠を表示」で生データと計算式を確認する。
③ 並列統括・低コスト化・スマホ遠隔操作（機能4・5・7）
❌ Before：複数ウィンドウを手動管理し、高価なモデルばかり使い、長いビルド中はPCの前に縛られる。
⭕ After：Projectsで自動スレッド分割、Haikuでコスト75%削減、/remotecontrol＋スリープ防止で外出先からスマホ操作。
